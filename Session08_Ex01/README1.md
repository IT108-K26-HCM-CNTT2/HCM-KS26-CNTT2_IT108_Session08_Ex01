# Giới thiệu dự án

## 1. Tổng quan

Dự án được thực hiện bởi nhóm sinh viên nhằm vận dụng kiến thức đã học vào thực tế. Nhóm sử dụng GitHub để lưu trữ tài liệu, quản lý phiên bản và phối hợp trong quá trình thực hiện.

## 2. Mục tiêu

- Áp dụng kiến thức đã học vào dự án.
- Phân chia công việc giữa các thành viên.
- Lưu trữ tài liệu dễ đọc và dễ chỉnh sửa.
- Sử dụng Git để theo dõi lịch sử thay đổi.

## 3. Công cụ sử dụng

| Công cụ | Mục đích |
|---|---|
| Notepad | Soạn thảo văn bản Markdown |
| StackEdit | Viết và xem trước Markdown trên trình duyệt |
| Git | Theo dõi lịch sử thay đổi |
| GitHub | Lưu trữ tài liệu và làm việc nhóm |

## 4. Quy trình thực hiện

1. Soạn thảo nội dung bằng Markdown.
2. Kiểm tra nội dung và định dạng.
3. Đưa tài liệu lên repository GitHub.
4. Theo dõi và cập nhật các thay đổi trong quá trình làm việc nhóm.
